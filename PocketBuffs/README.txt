SatchelSense - Settings Import

This small compatibility component is included with SatchelSense so WoW can
load each character's saved settings from the older addon name automatically.
Keep it enabled. It provides no separate grid, item actions or keybindings.

Its folder remains PocketBuffs only to locate the existing character save.
SatchelSense imports the old profile once into SatchelSenseDB and leaves the
original data intact. No files under WTF need to be edited, moved or deleted.
