Leather frame prompt:
Use case: game UI texture / logo-brand. Reference image is ONLY a material and palette reference for its beautiful dark brown leather bag, not an edit target. Create ONE square UI perimeter frame asset on a genuinely transparent background with a genuinely transparent open center. It should resemble the soft leather mouth and seams of an open fantasy adventurer's pouch, viewed straight on, suitable to frame a clickable item grid. Broad softly bulging rounded lower corners, folded leather rolled top lip, supple irregular organic leather edges. Quiet tiny muted tan stitching, dark chestnut/charcoal leather grain, soft natural warm highlights. NO bright gold line, NO yellow outline, NO hard square geometry, NO shiny metal rim, NO clasp, NO items, NO potion, NO scroll, NO text. The leather is ONLY the perimeter band around a large transparent central opening. Frame fills square canvas nearly edge to edge with 3% outer transparent safety. Perimeter thickness around 10% of canvas, corner curvature inside outer 25% at each corner. Mostly straight middle half of each side so the asset can be sliced into repeatable edges and fixed corners for a resizable game UI. No leather backing or background behind the central opening. High quality hand-painted fantasy inventory material, tactile but visually quiet. No shadows filling the hole.

Gentle natural warm highlights, dark quiet center for an interactive icon to be overlaid later. Match reference leather. NO button, NO icon, NO gold, NO metal, NO clasp, NO holes, NO letters, NO symbols, NO bright outlines. The patch itself is solid leather with transparent surroundings, centered front view, clean alpha, hand-painted fantasy inventory UI material.
