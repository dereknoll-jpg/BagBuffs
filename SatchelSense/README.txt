SatchelSense 1.0.0-rc.5 - WoW Forever, interface 16001

Good things. Already in your bags.

Install BOTH SatchelSense and PocketBuffs folders from the ZIP in _forever_/Interface/AddOns.
PocketBuffs is now the bundled SatchelSense - Settings Import component, with no HUD.
Keep it enabled to load legacy profiles. Restart WoW after the rename.
Existing settings, saved slots and item keys import once without changing the old save.
Older native grid-slot keys and /pbuff or /pocketbuffs shortcuts continue to work.
Open settings with /satchel, right-click an item, or click the small pouch icon.
Middle-click a grid item to hide it outside combat, locked or unlocked.
Restore hidden items under Items & Keys; their item keys remain assigned.
Left-click items to use on yourself. Enhancements use the normal item cursor.
Shift-right-click the pouch icon to lock or unlock without opening settings.
When unlocked, drag the pouch icon (or wide-layout DRAG tab) to move the grid.
Unlock to drag grid items directly into saved slots, with or without settings open.
Empty slots show faint drop targets only while unlocked. Occupied slots swap.
Lock the position to restore normal click-to-use and prevent direct rearrangement.
Auto sorting is ON by default: new items sort by type and empty gaps close.
Drag or choose Manual to keep exact slots and append new items after the layout.
Switching to Auto retains the saved manual layout for later restoration.
Ctrl-left-click pouch: sort by type now. Right-click pouch: quick menu.
Compact only closes gaps without changing item order.
New discoveries glow gold briefly; toggle this in Layout or the quick menu.
Editing hit areas hide automatically in combat; item actions stay intact.
Mouse wheel over an item to change pages outside combat.

Layouts: /satchel layout 3x3, /satchel layout 1x8, /satchel layout 8x1
Other commands: /satchel help

Items & Keys tab: drag item icons or use < / > to set grid order.
Auto / Manual selects ongoing sorting or saved positions.
By type / A - Z sorts now; in Auto it also chooses the ongoing sort style.
Click Bind key beside an item, then press a key or mouse button/wheel.
Escape cancels capture. Backspace/Delete clears the binding.
Occupied keys ask for confirmation; normal game bindings are preserved.
Item keys follow the item through sorting and pages and save per character.

Empty slots are transparent. Identical stacks merge.
Favorites sort first in automatic modes; manual order takes precedence.
Centered cooldown numbers use real item cooldowns and Recently Bandaged expiry.
Unknown debuff expiration shows ? rather than a guessed time.
Plain food/drink is optional and off by default.
Buttons retain their item IDs and positions throughout combat.
New items and page/layout changes wait until combat ends.
Put emergency items on the first page before combat.

Release candidate: offline checks pass; native input/combat needs live review.
English tooltip and name matching; full localization is not included.
Unusual items may need /satchel include ITEMID.
The game enforces use restrictions and native equipment targeting.
No automatic item consumption, stacking inference, or best-item recommendations.

Original pouch branding was generated with AI assistance for this addon.
