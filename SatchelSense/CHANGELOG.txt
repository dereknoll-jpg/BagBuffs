1.0.0-rc.5 - Quick hide
- Middle-click a grid item to add it to the hidden list without opening settings.
- Works with the grid locked or unlocked, outside combat.
- Restore hidden items under Items & Keys. Existing item keybindings stay assigned.
- Added shortcut hints to item tooltips.

1.0.0-rc.4 - Automatic organizing
- Auto sorting is now enabled by default, including on upgrade.
- New supplies sort into the grid by type, filling earlier pages before adding another.
- Used-up, removed and hidden items no longer leave gaps in Auto mode.
- Optional Manual mode retains exact positions and appends new items after the saved layout.
- Existing manual layouts are saved and can be restored by choosing Manual.
- Dragging or using move arrows automatically switches to Manual mode.
- Ctrl-left-click the pouch to sort by type and close gaps immediately.
- Right-click the pouch for a quick menu with Auto/Manual, Compact only and other controls.
- Compact only closes gaps while keeping the current item order.
- New discoveries briefly glow gold; toggle highlights in Layout or the quick menu.
- Sorting pauses during combat and active drags. Existing settings and item keys carry over.

1.0.0-rc.3 - SatchelSense rebrand
- Renamed the addon, settings window, commands, artwork and release packages to SatchelSense.
- Added automatic per-character import of existing PocketBuffs profiles.
- Preserved saved positions, layouts, slots, filters, favorites and item keybindings.
- Kept older native grid-slot keys and /pbuff or /pocketbuffs commands working.
- Included a small SatchelSense - Settings Import component under the legacy folder name.
- Updated the CurseForge description, banner and feature sheet with automatic pickup discovery.
- Exported every gallery image below 2 MB.

1.0.0-rc.2
- Fixed stuck floating item drags when the client omits the source drag-stop callback.
- Drops finish on mouse-up, global release or physical-button polling.
- Drop targeting uses cursor coordinates and handles UI scaling.
- Unlocked grids show faint empty-slot targets; drop into an empty slot or swap occupied slots.
- Saved slot positions now survive locking, bag changes, reloads and item reacquisition.
- Newly discovered supported items append after the existing saved layout.
- Locking disables direct grid dragging even when the settings window is open.
- Existing manual order and item bindings migrate without resetting the profile.

1.0.0-rc.1

- Added Shift-right-click on the pouch icon to lock/unlock without opening settings.
- Added dragging the unlocked pouch icon to move the whole grid.
- Added a separate editing hit layer; original item actions remain intact during dragging.
- The game's combat visibility driver hides the editing layer during combat.
- Added canceled-drop handling and dragging between editor rows and the live grid.
- Fixed move-handle overlap on narrow vertical layouts.
- Prepared static CurseForge artwork, listing text and an upload kit.
